Website Design for Chabad Houses and Shluchim

New sites, refreshes, mini sites, camp sites — anything website. Custom-coded or on a platform, built to look professional and keep running.

Three ways to build a Chabad House website

Custom code site

Built from scratch in code. Hosted free on GitHub Pages. No platform fees, no monthly costs, no template constraints. The most advanced design possible. Best for camps, event microsites, one-time dinners, programs that don't need frequent complex layout changes, any project where design quality matters more than self-editing flexibility.

Platform build (Squarespace or similar)

Squarespace or similar. Client or their office gets a real drag-and-drop editor and can update the site independently. Platform fees run $15–30/month. Design is constrained by what the platform allows. Best for active community sites with frequent updates that need to be managed independently without coming back to ShliachFlow every time.

Work inside ChabadOne or ChabadSuite

Working within an existing institutional platform the client is already on. On ChabadOne, inner pages give full source HTML access, so I can build fully custom-designed pages for events, campaigns, or programs. On ChabadSuite, HTML embed blocks let me inject custom-designed sections into pages. Best for shluchim already on ChabadOne or ChabadSuite who want a professional campaign page, event landing page, or program site without switching platforms.
